# ServiceCore

Aplicacao web demonstrativa chamada **ServiceCore**, desenvolvida pela **GT Core**.

O ServiceCore e uma plataforma para gestao de ordens de servico, atendimentos tecnicos e operacoes de campo. O projeto foi criado como portfolio profissional, com aparencia de produto SaaS moderno e pronto para uso, utilizando apenas dados simulados localmente.

## Objetivo

Demonstrar uma experiencia empresarial completa para empresas prestadoras de servico que precisam controlar clientes, equipamentos, tecnicos, atendimentos e ordens de servico em um unico lugar.

O sistema transmite organizacao, produtividade e controle operacional, destacando capacidade de desenvolvimento de interfaces modernas para sistemas corporativos.

## Funcionalidades demonstrativas

- Dashboard com indicadores operacionais.
- Gestao visual de ordens de servico.
- Listagem de clientes, equipamentos e tecnicos.
- Agenda tecnica e acompanhamento de produtividade.
- Busca e filtros locais.
- Detalhamento de OS com historico e timeline.
- Dados mockados para simular um produto real.

## Escopo

Este projeto nao implementa backend, autenticacao real ou banco de dados.

Todas as informacoes sao ficticias e simuladas no front-end, exclusivamente para fins demonstrativos e de portfolio.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Execucao

Abra o arquivo `index.html` diretamente no navegador.

Como a aplicacao e estatica, nao e necessario configurar servidor, banco de dados ou variaveis de ambiente.
