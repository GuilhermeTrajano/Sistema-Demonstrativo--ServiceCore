# ServiceCore

Aplicação web demonstrativa chamada **ServiceCore**, desenvolvida pela **GT Core**.

O ServiceCore é uma plataforma para gestão de ordens de serviço, atendimentos técnicos e operações de campo. O projeto foi criado como portfólio profissional, com aparência de produto SaaS moderno e pronto para uso, utilizando apenas dados simulados localmente.

## Objetivo

Demonstrar uma experiência empresarial completa para empresas prestadoras de serviço que precisam controlar clientes, equipamentos, técnicos, atendimentos e ordens de serviço em um único lugar.

O sistema transmite organização, produtividade e controle operacional, destacando a capacidade de desenvolvimento de interfaces modernas para sistemas corporativos.

## Funcionalidades demonstrativas

- Dashboard com indicadores operacionais.
- Gestão visual de ordens de serviço.
- Listagem de clientes, equipamentos e técnicos.
- Agenda técnica e acompanhamento de produtividade.
- Busca e filtros locais.
- Detalhamento de OS com histórico e timeline.
- Dados mockados para simular um produto real.

## Escopo

Este projeto não implementa backend, autenticação real ou banco de dados.

Todas as informações são fictícias e simuladas no front-end, exclusivamente para fins demonstrativos e de portfólio.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Execução

Abra o arquivo `index.html` diretamente no navegador.

Como a aplicação é estática, não é necessário configurar servidor, banco de dados ou variáveis de ambiente.
